# Start querying agent evidence

Unisphere answers questions about **supplied local evidence**. It does not contact remote services, execute agent commands, or assume the current directory is in scope. Choose one scope on each query:

- live repository: `--repo PATH` (explicit `.` is allowed);
- one known source: `--source PATH_OR_ID`;
- saved versioned query data: `--input FILE` or `--input -`.

Start with `unisphere sources list --repo . --format json`, inspect `data.coverage`, then select a local `q1:` ID. A zero-match query is successful and suggests how to inspect scope or coverage. A partial query is successful only with `--allow-partial` and remains labelled partial.

## Command reference

Every example uses the packaged synthetic fixture or an explicit repository. `SESSION_ID`, `TURN_ID`, `MESSAGE_ID`, `TOOL_ID`, `EVENT_ID`, and `SOURCE_ID` are named bindings returned by an earlier command; they are not literal placeholders to paste.

| Command | Motivating question and useful use case | Prerequisite | Example | Expected evidence and interpretation | Limits | Recovery | Next action |
|---|---|---|---|---|---|---|---|
| `unisphere docs list` | What can this installed version teach offline? Discover version-matched workflows before touching any source. | Installed binary only. | `unisphere docs list --json` | Topic IDs, titles, summaries, and related topics; no source was inspected. | Static topics for this release. | Unknown options return safe valid alternatives. | Run `unisphere docs get start`. |
| `unisphere docs get TOPIC` | How do I complete one workflow? Read a bundled guide on an offline host. | A topic from `docs list`. | `unisphere docs get privacy-and-coverage` | Complete Markdown for the requested exact topic. | No fuzzy or remote lookup. | An unknown topic names valid topic IDs; choose one exactly. | Follow the guide's labelled next step. |
| `unisphere schema show DATASET` | Which fields, filters, formats, and losses are supported? Generate a pipeline without guessing columns. | Dataset: `sources`, `sessions`, `turns`, `messages`, `tools`, or `events`. | `unisphere schema show tools --json` | Versioned field types, sensitivity, availability, operations, grouping, metrics, defaults, formats, and losses. | Source-qualified availability can still vary. | Invalid fields/datasets name valid alternatives and the relevant schema command. | Build a metadata-only query from declared fields. |
| `unisphere config check` | Is an explicit configuration valid? Diagnose settings without opening session stores. | Optional explicit config path or source-root overrides. | `unisphere config check --json` | Effective validated configuration and a next step; not source readiness. | Configuration inspection only. | Fix the stable configuration code/location before retrying. | Run `unisphere adapters list --json` or an explicitly scoped query. |
| `unisphere adapters list` | Which registered representations can this binary describe? Choose a source adapter intentionally. | Installed binary only. | `unisphere adapters list --json` | Static catalog capabilities and location hints, not detected installations. | Hints do not prove a source exists. | Use a listed adapter ID; do not guess aliases. | Run `sources list` with an explicit scope. |
| `unisphere sources list` | Which stores supplied evidence for this scope? Diagnose missing sessions before searching content. | Exactly one live or offline scope. | `unisphere sources list --repo . --format json` | Stable source IDs, adapter/harness, revision, read status, association and coverage. | Default 50 rows; bounds still apply to `--limit 0`. | Missing/unreadable/unsupported are failures unless partial reads are explicitly accepted where allowed. | Bind one `SOURCE_ID`, then run `sources show` or `sources check`. |
| `unisphere sources show SOURCE_ID` | What provenance and availability belong to one source? Audit a result before relying on it. | Exact local source ID plus its original scope. | `unisphere sources show "$SOURCE_ID" --repo . --format json` | One source with revision-qualified provenance; absence does not mean an empty transcript. | IDs are local to a query view. | Rediscover after a view change; choose a listed candidate if identity is ambiguous. | Inspect associated sessions or run `sources check`. |
| `unisphere sources check --source SOURCE_ID` | Why was a source rejected, partial, or unassociated? Repair discovery without opening unrelated stores. | Exact source ID. | `unisphere sources check --source "$SOURCE_ID" --format json` | Typed read/association issues and safe recovery. | Does not mutate or repair a source. | Change the named prerequisite: path, permission, dialect, stable revision, or trusted Git capability. | Repeat `sources list` after the prerequisite changes. |
| `unisphere sessions list` | Which runs are associated with this repository? Find a review target across supported harnesses. | Explicit scope. | `unisphere sessions list --repo . --harness claude --format json` | Local session IDs, qualified counts, model/name observations only when supported, and coverage. | Native IDs are not global; default 50 rows. | Inspect coverage on zero matches; use `--source` for known unassociated evidence. | Bind one `SESSION_ID`, then run `sessions show` or `sessions tree`. |
| `unisphere sessions show SESSION_ID` | What supports this run? Confirm provenance before quoting or aggregating it. | Exact session ID and original scope. | `unisphere sessions show "$SESSION_ID" --repo . --format json` | One session, supporting source refs, lineage and source-qualified availability. | Metadata does not imply transcript completeness. | Select an exact candidate/branch or reopen the changed view. | Inspect turns or lineage. |
| `unisphere sessions tree SESSION_ID` | Did this run fork, delegate, compact, or resume? Review lineage without inventing chronology. | Exact session ID and original scope. | `unisphere sessions tree "$SESSION_ID" --repo . --format json` | Evidence-backed parent/fork/subagent/compaction links and dangling/conflict facts. | Equal IDs/text do not prove ancestry. | Choose a listed branch; unresolved links remain explicit. | Query turns for one selected branch. |
| `unisphere sessions stats` | How much observed activity is represented? Compare source-qualified counts without ranking agents. | Explicit scope and, for exact totals, resolved identity/completeness. | `unisphere sessions stats --repo . --group-by harness --format json` | Counts/usage with universe and coverage qualifiers. | No cost, productivity, quality, or complete-history inference. | Use `--unresolved separate` only when separate uncertain groups are acceptable. | Inspect an interesting session or source coverage. |
| `unisphere sessions extract` | Can I carry selected conversation evidence into review? Produce a bounded artefact with provenance. | Explicit scope; `--include-content` for names/bodies. | `unisphere sessions extract --input synthetic-query.json --include-content --format markdown` | Labeled session sections and approved nested projections. | Markdown/text are lossy presentations; no cross-branch synthetic timeline. | Select an explicit branch or use metadata-only JSON. | Review the emitted coverage summary on stderr. |
| `unisphere sessions export` | How do I convert one explicit native input to OTLP JSONL? Feed an existing telemetry pipeline. | Native `--input`; native adapter when required. | `unisphere sessions export --input session.jsonl --adapter claude-code` | OTLP LogsData bytes only on stdout; guidance is diagnostic, never a data row. | Native export is not query extraction or persistent history. | Fix the named native input/dialect/output failure; never treat partial bytes as complete. | Validate the downstream importer or inspect with query commands separately. |
| `unisphere turns list` | Which user-request episodes match? Locate a multi-tool or error-bearing episode. | Explicit scope. | `unisphere turns list --repo . --has-errors --format json` | Stable branch-qualified turn IDs and one-based ordinals. | Reconstruction is source/version qualified; tool responses are not new user turns. | Use schema-declared filters; select a session for `--range`. | Bind `TURN_ID`, then run `turns show`. |
| `unisphere turns show TURN_ID` | What records belong to this episode? Inspect one request boundary without flattening branches. | Exact turn ID and original scope. | `unisphere turns show "$TURN_ID" --repo . --format json` | One turn with message/call memberships and boundary basis. | Membership may be unavailable for unsupported formats. | Choose a candidate branch or use events when higher-level reconstruction is unavailable. | Extract this turn or inspect its tools/messages. |
| `unisphere turns stats` | How many selected turns and source-qualified usage observations exist? Summarise a bounded review set. | Explicit scope. | `unisphere turns stats --repo . --group-by tool_families --format json` | Counts and compatible usage buckets over matched logical turns. | Replayed prefixes/cumulative snapshots are not blindly summed. | Inspect schema for allowed groups/metrics; supply needed fields in offline input. | Drill into matching turns. |
| `unisphere turns extract` | What context surrounds matching episodes? Prepare review evidence around errors. | Explicit scope; content consent for payload output. | `unisphere turns extract --repo . --has-errors --context-before 1 --context-after 1 --include-content --format jsonl` | Turn rows carry metadata-only `is_context` (`false` match, `true` added neighbour); human formats label `match`/`context`; matched/emitted counts can differ. | Context never crosses admitted authority; `is_context` is not a filter; `--range` needs one session/branch. | Supply complete saved partition metadata or narrow ambiguity. | Inspect diagnostic coverage and the selected call IDs. |
| `unisphere messages list` | Which recorded messages match a role or literal? Find requests without emitting their bodies. | Explicit scope; searching sensitive fields permits local inspection only. | `unisphere messages list --repo . --role user --contains rollback --format json` | Matching IDs/roles/timestamps; text stays omitted without content consent. | Literal `--contains` is not regex and does not authorize output. | Use `--regex` explicitly for a bounded pattern; inspect schema for available fields. | Bind `MESSAGE_ID` or extract with deliberate consent. |
| `unisphere messages show MESSAGE_ID` | What is one supported message projection? Inspect a selected request or response. | Exact message ID; content consent for `text`/`parts`. | `unisphere messages show "$MESSAGE_ID" --repo . --include-content --format json` | Approved message parts, role, memberships and provenance. | Unsupported/opaque parts remain unavailable; no attachment fetch. | Choose metadata-only columns or deliberately add consent. | Inspect its turn or extract neighbouring context. |
| `unisphere messages extract` | How do I quote a bounded set with neighbours? Assemble a review packet. | Explicit scope; complete partition data for offline context. | `unisphere messages extract --repo . --role user --context-after 1 --include-content --format markdown` | Machine rows carry metadata-only `is_context`; human formats use separate session/branch sections with `match`/`context` labels. | Context can escape time filters but not source/participant authority; `is_context` is not a predicate. | Use complete JSON input or remove context; resolve branch ambiguity. | Verify coverage, then use the packet for human interpretation. |
| `unisphere tools list` | Which invocations failed, timed out, or remain incomplete? Diagnose command reliability. | Explicit scope. | `unisphere tools list --repo . --status failed --format json` | One row per invocation with outcome, optional exit/duration and evidence basis. | Missing completion is not success; unknown duration is not zero. | Inspect source coverage or select another supported tool field. | Bind `TOOL_ID`, then run `tools show` or `tools stats`. |
| `unisphere tools show TOOL_ID` | What evidence supports one call outcome? Audit a failure before assigning cause. | Exact tool ID; consent for command/input/output. | `unisphere tools show "$TOOL_ID" --repo . --include-content --format json` | Call/result/progress refs, status and supported timing basis. | Unisphere supplies evidence, not root-cause analysis. | Use metadata-only output or deliberate content consent; unresolved pairing remains explicit. | Inspect the parent turn and source refs. |
| `unisphere tools stats` | What are measured latency and outcome distributions? Find a slow/failure hotspot without hiding missing samples. | Explicit scope. | `unisphere tools stats --repo . --group-by tool_family --metric count --metric failures --metric p95_ms --format json` | Count, measured/missing duration counts, terminal denominator and nearest-rank metrics in ms. | Incomplete/unknown are not successes; no causal/productivity claim. | Use schema-listed metrics/groups; retain missing-duration counts. | List calls in the group before drawing a conclusion. |
| `unisphere tools extract` | Which approved call inputs/results support a diagnosis? Create a bounded payload extract. | Explicit scope and `--include-content`; choose `--part`. | `unisphere tools extract --repo . --status failed --part output --include-content --format jsonl` | Selected call rows with approved output and provenance. | No automatic execution, replay, sidecar, or URL access. | Remove payload fields or add explicit consent; narrow if a resource bound is hit. | Review the parent turns and coverage summary. |
| `unisphere events list` | Which low-level observations could not become higher-level rows? Debug reconstruction gaps. | Explicit scope. | `unisphere events list --repo . --format json` | Source-derived event IDs, kinds, timestamps and optional memberships. | An event is not automatically a turn, call, model inference, or OTel span. | Query sources/coverage for unsupported or partial representations. | Bind `EVENT_ID`, then run `events show`. |
| `unisphere events show EVENT_ID` | What provenance supports one observation? Audit a reconstruction boundary. | Exact event ID and original scope. | `unisphere events show "$EVENT_ID" --repo . --format json` | One event with source refs and available higher-level links. | Payload parts require consent and may remain unsupported. | Choose metadata-only output or add deliberate consent. | Inspect its linked message/call/turn when present. |
| `unisphere events extract` | Can I preserve selected debugging observations? Export a machine-readable evidence subset. | Explicit scope; consent for `parts`. | `unisphere events extract --repo . --include-content --format jsonl` | Clean typed event rows; summary/action remains on stderr. | JSONL EOF alone does not prove original-source completeness. | Prefer complete JSON extraction when later context/reconstruction is required. | Save the diagnostic coverage with the data. |

## Interpretation boundary

Unisphere supplies selected rows, local identities, source references, availability, coverage, and declared calculations. A human or downstream system decides whether evidence is relevant, why a call failed, whether work was good, or what action to take. Suggested commands are printed but never executed automatically.
