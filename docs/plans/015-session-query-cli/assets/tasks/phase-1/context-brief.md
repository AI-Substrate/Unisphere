## Execution and proof

Core/adapter/loader/SDK edge cases plus a throwaway external SDK discovery smoke; full installed CLI/recipe acceptance is phase3. Output/docs can be authored concurrently in guide wave1; phase gates are outcome checkpoints, not a reason to serialize independent source work.

Native parsers emit typed facts; SDK owns shared identity/reconstruction/filter/context/statistics/privacy; the CLI only parses, composes and presents. Preserve the one application registry and existing native data streams. Use the guide's fakes instead of same-wave sibling implementations. Every command outcome has a useful next action and every error a safe cause-specific recovery.

PM owns quality and shared-file convergence. Worker code remains a candidate until inspected, integrated, exercised and independently reviewed; reject or rewrite weak code. No arbitrary abstraction, avoidable whole-graph copying, fabricated evidence, mocked success or wording-pinning tests. No project-wide validation while concurrent edits are in flight. No real user-store mutation, retired telemetry reader, automatic agent execution, global tooling changes or unapproved publication.

A passing existing boot proves only its observed native scope. All new assertions remain unchecked until their actual commands run against the relevant source.
